# cli-anything-photoshop — agent harness

Generated by the CLI-Anything 7-phase methodology for
**Adobe Photoshop 2026** (`/Applications/Adobe Photoshop 2026/Adobe
Photoshop 2026.app`, scripting version 27.10.0, macOS).

- `PHOTOSHOP.md` — automation-surface analysis + harness SOP + verified engine facts
- `setup.py` — PyPI-style install (`pip install -e .`), console script
  `cli-anything-photoshop`
- `cli_anything/photoshop/` — namespace package: CLI, core domains, backend,
  REPL skin, skills, tests
- `skills/cli-anything-photoshop/SKILL.md` — canonical agent skill file
- `examples/` — end-to-end workflow scripts

Quick start:

```bash
python3 -m venv .venv && .venv/bin/pip install -e .
.venv/bin/cli-anything-photoshop --help
.venv/bin/cli-anything-photoshop --json app info
```

The Photoshop application is a hard dependency: it auto-launches on demand
and performs every mutation itself.
